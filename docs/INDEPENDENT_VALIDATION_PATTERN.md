# Independent Validation Pattern

Reference pattern for independent evaluation before deployment authorization.

## Controls

- Exact subject, version, and configuration binding.
- Independent evaluator with interest disclosure.
- Defined assessment domains.
- Benefit-risk evidence.
- Deployment-readiness opinion (non-binding).
- Human-operable shutdown evidence for high-consequence systems.
- Material-change revalidation.
- Protected concern handling that can affect assurance validity.

## Boundary

This pattern informs design only. It does not assert compliance, certification, or authorization. Authority effect remains NONE until an authorized institutional decision explicitly changes it.
