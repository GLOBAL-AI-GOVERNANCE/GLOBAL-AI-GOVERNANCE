# Problem-Solving Model

GLOBAL-AI-GOVERNANCE converts real AI problems into bounded, evidence-driven, testable solutions and keeps them open until verified closure or an explicitly documented external dependency.

## Loop

```text
PROBLEM
↓
SOURCE + EVIDENCE
↓
VERIFY WHAT IS ACTUALLY KNOWN
↓
BOUND THE SYSTEM / ACTORS / CONSEQUENCES
↓
IDENTIFY FAILURE MODE
↓
ASSIGN ACCOUNTABLE OWNER
↓
DESIGN CONTROL
↓
DEFINE TEST / ACCEPTANCE CRITERIA
↓
GENERATE EVIDENCE
↓
INDEPENDENTLY VERIFY WHERE REQUIRED
↓
HUMAN DECISION
↓
MONITOR
↓
VERIFIED CLOSURE
        ↘
      REOPEN ON MATERIAL CHANGE
```

## Governance Problem Record (cross-portfolio)

```text
problem_id:
title:
source: { type, reference, date, claim_status }
subject: { system_id, version, configuration }
problem: { failure_mode, affected_parties, potential_harm, severity, reversibility }
owner: { accountable_human, responsible_team }
controls: { preventive, detective, containment, recovery }
evidence: { required, available, gaps }
validation: { test_plan, evaluator, independence_status, acceptance_criteria }
decision: { disposition, rationale, authority }
closure: { criteria, verification_required, closed, reopen_triggers }
```

No problem without a path to closure.
