# Maturity Model

Maturity labels communicate what evidence exists today. They are not quality rankings and do not imply certification, compliance, or production authorization.

- **Foundational reference:** concepts, templates, or models intended to support other work.
- **Pre-alpha / preimplementation:** design artifacts exist, but implementation is absent or intentionally gated.
- **Experimental public alpha:** implemented semantics are available for experimentation with explicit limitations.
- **Pre-release / review candidate:** a bounded candidate exists and remains subject to named validation or release gates.
- **Public defensive reference:** a defensive framework or reference package exists without claiming deployed operational effectiveness.
- **Working public reference toolkit:** an end-to-end reference workflow is implemented and testable within its stated boundary.

Repository-specific language remains authoritative when it is more precise than these portfolio categories.
