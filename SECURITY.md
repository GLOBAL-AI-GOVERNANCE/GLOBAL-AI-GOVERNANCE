# Security Policy

This repository does not operate an external security-report intake. Do not place secrets, credentials, personal data, sensitive operational information, or vulnerability material in public GitHub surfaces.

## Security Scope

Security-relevant failure classes for this repository include:

- Portfolio metadata (`portfolio.json`) that diverges from the repositories it describes
- Schema or contract definitions that permit authority transfer or weaken `authority_effect: NONE`
- Status, maturity, or release wording that overstates evidence
- Broken or redirected links to release assets, schemas, or install commands
- Workflow supply-chain risk

## Principle

> No trust without verification.
